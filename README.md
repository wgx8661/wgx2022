# 英语单词学习网站（PHP）

这是一个用 PHP 编写的轻量级英语单词学习网站，包含：

- 单词卡片学习（单词、音标、中文释义、例句）
- 标记“已掌握”进度（Session）
- 选择题测验（随机题序 + 自动计分）

## 运行环境

- PHP 8.0+（7.4 一般也可运行）
- 浏览器（Chrome / Edge / Safari 等）

## 如何运行代码

在项目根目录执行：

```bash
php -S 0.0.0.0:8000
```

看到类似输出表示启动成功：

```text
PHP ... Development Server (http://0.0.0.0:8000) started
```

然后在浏览器打开：

- 本机访问：`http://127.0.0.1:8000`
- 如果你在远程服务器上运行，请替换为服务器 IP，例如：`http://你的服务器IP:8000`

## 常见问题

### 1) 提示 `php: command not found`
说明未安装 PHP。请先安装 PHP 并确认 `php -v` 可用。

### 2) 样式没有加载
确认 `styles.css` 与 `index.php` 在同一目录，并通过 HTTP 访问页面（不要直接双击打开 PHP 文件）。

### 3) 已掌握/测验分数没有保存
该项目用 `$_SESSION` 保存状态。请不要禁用浏览器 Cookie，并在同一浏览器会话中访问。

## 代码文件

- `index.php`：页面与功能逻辑
- `words.json`：单词数据文件（可自行增删）
- `styles.css`：样式
